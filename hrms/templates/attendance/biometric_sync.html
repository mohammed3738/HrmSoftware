Rebuild from stored punches

Re-applies the in/out time rules to a date range using punches already held here. It fetches nothing from the punch machine — the agent on the Windows server does that — so it is safe to run at any time. Days whose times were set by hand, days inside a finalized payroll run and days before an employee joined are left alone.

The rules in force

Day shift

  • In-time: the day's first punch, set once and then left alone.
  • Out-time: the day's last punch, refreshed whenever a later one appears.

Night shift

  • In-time: that day's last punch (from {{ night_in_from|time:"H:i" }} onwards).
  • Out-time: the next day's first punch (before {{ night_out_until|time:"H:i" }}).

A span longer than {{ max_shift_hours }} hours is treated as a missed out-punch and the out-time is left blank rather than crediting the day.
